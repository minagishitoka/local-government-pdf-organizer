# local-government-pdf-organizer

自治体議会資料のPDFを、研究・AI解析に耐える形へ整理するためのPythonツールです。

## 目的

大量の自治体議会資料PDFについて、次の処理を一連で行います。

1. PDFを検査する
2. Geminiで資料冒頭から自治体名・開催日・正式タイトルを取得する
3. AIから取得した自治体名・開催日・タイトルを機械的に検証する
4. 原本を変更せず、「自治体名_開催日_資料タイトル.pdf」の形式で整理済みコピーを作る
5. 1000ページ・150MBを目安にPDFを結合する
6. 原本と結合後ページの対応表をPDF先頭に付ける
7. 結合PDFをTXTへ変換する
8. TXTだけを入力としてWordを生成する
9. CSV・state.jsonで処理状況と対応関係を記録する

## なぜPDFをTXT・Wordにするのか

TXT/Word化は単なる書式変換ではありません。

大量の議会資料をClaude等のAIへ投入する際、PDFにはページ数や視覚解析に関する形式固有の制約があります。そのため、文字情報を持つPDFについては、まずPython（PyMuPDF）で文字を抽出し、AI投入用のテキスト資料へ変換します。

Wordは最終的な閲覧資料というより、資料境界・見出し・PDFページ番号を保持したAI解析用コンテナとして扱います。

なお、画像だけのスキャンPDFでは文字抽出できない場合があります。その場合は抽出失敗を隠さず要確認として残し、原PDFを別途確認する方針です。

## 基本設計

```text
原PDF
  ↓
機械検査
  ↓
Geminiによるタイトル候補取得（冒頭3ページ）
  ↓
AI出力検証
  ↓
原本を保護したリネームコピー
  ↓
対応表作成
  ↓
PDF結合（1000ページ・150MB上限）
  ↓
結合PDF検証
  ↓
PDF → TXT
  ↓
TXT → Word
  ↓
Claude / Gemini等で研究・解析
```

## 安全方針

- 原本PDFは変更しない
- 異常PDFを黙ってスキップしない
- AIのタイトルを無条件に信用しない
- AIタイトルが怪しい場合は元ファイル名へフォールバックし、要確認にする
- 結合前後でページ数・しおり・遷移先を検証する
- TXT/Word工程でも資料欠落を検知する
- state.jsonで途中状態を保存し、再実行可能にする

## 査読

2026-09-16時点で、GeminiとClaudeに独立したコードレビューを依頼しました。両者とも「軽微な修正後に実用投入可能」と評価し、異なる観点から問題を発見しました。

- Gemini: API 429耐性、TXT→Word境界文字列衝突などを指摘
- Claude: 同名ファイル衝突時の `.pdf.pdf` 再発バグ、TXT→Word資料欠落検知不足を指摘

これらは開発履歴とテスト計画に記録します。


## Gemini無料耐久版

通常版の `main.py` はそのまま残し、`main_free.py` を追加しています。

`main_free.py` は「APIを使わない版」ではありません。Google Gemini APIを使いつつ、無料枠・低いレート上限でも大量のPDFを処理しやすくするための節約版です。

### 無料耐久版の仕組み

1. まずPythonがPDF冒頭3ページを読み、自治体名・開催日・タイトル候補を機械的に抽出
2. 3項目が明確ならGemini APIを呼ばず、そのまま採用
3. どれかが曖昧なPDFだけGeminiへ送信
4. API呼び出しは同時実行1件
5. API呼び出しの間隔をデフォルト4秒空ける
6. 1回の実行でGeminiを最大60回までに制限
7. ローカルの使用量記録で1日100回までに制限
8. 429 / RESOURCE_EXHAUSTED時は無理に連打せず待機
9. `state_free.json` に処理済み情報を保存し、再実行時にAPIを再利用しない
10. 通常版とは出力フォルダ・stateファイルを分離

### 出力先

無料耐久版では通常版の成果物を上書きしないよう、次のフォルダを使用します。

- `整理済み_無料耐久/`
- `結合PDF_無料耐久/`
- `レポート_無料耐久/`
- `TXT_無料耐久/`
- `Word_無料耐久/`
- `state_free.json`
- `free_api_usage.json`

### 実行

通常版:

```text
python main.py
```

無料耐久版:

```text
python main_free.py
```

APIキーはどちらもGemini API用のものを使用します。

なお、Gemini APIのレート制限はプロジェクト・モデル・利用ティアによって異なり、RPM・TPM・RPDの複数の上限があります。そのため無料耐久版の「4秒間隔」「1日100回」などはGoogleの公式上限そのものではなく、事故防止のための保守的なローカル設定です。実際の上限はGoogle AI Studioで確認してください。
